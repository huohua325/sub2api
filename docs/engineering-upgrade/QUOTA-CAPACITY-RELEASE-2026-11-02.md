## 实施取舍与边界

- 容量换算是只读投影，无迁移、无新退款。代价：回退旧程序后会恢复旧显示口径，不能回退数据库。
- 未核实历史仅按匹配窗口和阶段证据重新估算，未知状态保留；缺少证据保留原估算。
  代价：无法恢复的精确个人归属仍然未知，不能宣称个人之和与官方读数完全对齐。
- 预留以最后一次 `reserved` 事件时间换算，周期仍按请求原开始时间。
  代价：依赖原有持久事件证明刷新时刻；旧无事件记录仅能沿用原开始时间。
- 个人归属与整窗费用估算分开展示。旧服务没有新状态字段时保留原接口兼容显示；
  新服务已返回状态时，不能以费用比例回填缺失账本。代价：旧服务的估算不具新账本精度。
- 自动化覆盖 375/768/1440px 以及 1440px 浏览器缩放 200% 的等效 720 CSS px 布局；
  未将 CSS zoom 当作原生浏览器缩放证据。原生缩放与人工视觉验收仍待实际查看。
- 独立复核不认证旧历史精确归属；以保留未知状态而非制造精确扣点处理。
- 线上查询延迟需以实际样本报告，不能据小事件表推断未来大规模性能。
