# 学员接入与额度可信度验收

日期：2026-10-27。已发布版本：`0.2.18-mile.20261027.connect1`；业务源码提交 `56e9e1cd8`。

## 实现

- 首页、开始使用页和真实接入面板复用 `connectionConfig.ts`。保留 Codex 原认证模式、模型目录的显式读取及其他客户端。用途由 `usage_kind + platform` 决定。
- 创建 Key 后用返回值和提交时的分组快照打开接入面板。创建与列表刷新独立处理；编辑保持原行为；未分配用途不自动改成其他用途。面板按需加载。
- 密钥默认遮罩，预览直接用占位密钥生成，避免不同转义形式漏出真实密钥。复制和单文件下载使用真实内容。关闭即销毁接入会话；复制、下载不声称已成功连接。
- API 实验分别提供 Responses、Messages、Gemini 示例。未知模型明确使用占位符；请求体、凭证头和启动脚本分开，避免将特殊密钥拼入终端命令。复杂平台保留原客户端入口。
- 额度明确标注“已用”，Coding 只展示比例与状态，实验保留人民币金额。展开后显示周期、北京时间、数据状态、页面读取及账本变动时间。
- 修正无账本记录时伪造 `updated_at = 当前时间` 的行为。未知时间留空，读取页面不会制造结算时间。新增字段不改鉴权、价格或额度计算。
- 合并手动、轮询与到期刷新，后台暂停轮询，返回刷新；到期保持旧读数，等待服务端确认。没有新增每卡请求或首屏历史统计。

## 浏览器与性能

脚本：`tools/review_connection_quota.cjs`。生产构建、固定 mock 业务数据，所有业务 API 被拦截；没有使用生产账号或真实密钥，没有实际收费模型请求。

覆盖 1440、1024、768、375 CSS px，另以 720 CSS px 验证 1440 屏幕等效 200% 缩放后的布局。后者是等效布局复核，不冒充浏览器原生缩放测试。

检查 Key 列表空间、长地址、面板滚动、密钥显隐、文件下载、Tab 焦点约束与返回、三种用途创建后转接、创建成功但列表刷新失败、旧指引锚点、周期绝对时间、未知与失败读数、实验金额及首屏请求。Firefox 使用视口截图，其余使用整页截图。

| --- | --- | --- |
| Chromium | 40 / 40，页面异常 0 | 完整多宽度布局与功能 |
| WebKit | 40 / 40，页面异常 0 | 完整多宽度布局与功能 |

Firefox 自动化在 `about:blank` 执行 `page.setViewportSize({width:1024,height:900})` 也会挂起；复验脚本因此保留其初始视口，避免把驱动限制误记为页面布局通过。Firefox 多宽度与原生 200% 缩放仍需在可正常调整视口的环境补验。脚本记录实际宽度，并对固定视口截图去重。
