# 管理员 API 备用：实现与验收

开发基线：`36c4b9418`。本功能默认关闭，当前仅管理员能够配置、查看和实际使用。
没有创建生产策略、导入供应商 Key、批准候选倍率或执行付费推理。
设计及历史工作量测算见[备用设计](SUBSCRIPTION-API-FALLBACK-DESIGN-2026-11-17.md)。

## 管理操作

管理员侧栏进入“API 备用”。先在账号管理中添加 API Key 账号并绑定统一编程分组，
凭证继续由原账号管理保存；备用策略只保存账号 ID，不复制凭证。

每条策略对应一个统一编程分组、平台和准确型号，配置母账号及备用账号、价卡、
点数／官方 USD、采购倍率、输入／输出上限、单次／北京时间每日／累计支出上限及到期时间。
三项身份建立后不可修改；需要另一个分组或型号时新建策略。修改价卡／预算产生新审批版本，
已有请求继续按发送前冻结的版本结算，累计费用不因改版本、跨日、关闭或重启而清空。

可先保存关闭的草稿。启用必须明确确认能力和配置审核，缓存价格必须显式提供，
填写 `0` 才表示经批准的免费缓存。能力核实包括同型号、原生 Responses、工具、流式、
标准档位、用量返回和 token 上限语义；保存及只读预览不会调用模型。

主池全部失效才可接管。每个母账号可填写有时限的订阅过期／官方额度耗尽／认证失效证据，
最长 24 小时；有新鲜、有效的官方耗尽读数时也可直接判定耗尽。普通限流、繁忙、网络故障、
空池或状态未知不构成付费许可。新健康读数、窗口结束或主池成员变化会阻止沿用旧证据。
手动暂停的主账号不能借备用绕过管理操作。

预览检查策略和主池条件；实际请求仍要完成请求兼容、原个人额度及预算的原子准入。
费用页汇总已结算、在途预留、待核实及今日占用；记录可按策略／状态筛选，展开查看回执、
供应商请求标识及审计依据。费用未知时拿供应商证据核实用量或确认未计费，不直接退款。
一键关闭只阻止新的付费发送，已发送请求和恢复器仍继续处理。

修改备用账号资料后须重新审核策略；账号行 ID 相同不代表供应商地址或凭证身份未变。
旧加密状态不能跟随被编辑过的账号迁移，必须新开会话。

## 运行边界

- 只覆盖管理员统一编程 HTTP Responses 文本和已核实的本地 function/custom/namespace 工具；
  GPT、Grok 独立配置。普通独立分组、普通用户和已有客户端配置不自动开放。
- 价格只支持已审核的单档 USD 价卡；输入保守上界最多 196608 token，输出由服务器落实上限。
  图片／媒体、托管工具、远程压缩、WebSocket、异步、未知服务档位和额外计费能力不自动付费。
- 旧订阅密文及仅有 `previous_response_id` 的会话不能跨供应商迁移。备用生成的推理密文只保存
  SHA256 来源摘要，同用户、Key、分组、型号且同备用账号才能续接；不存原文。
  恢复订阅或关闭备用后，这类状态会话提示新开，不把密文发往另一个账号。
- 本版拒绝设有独立金额总额／滚动限额的 Key，以及设有旧金额限额的备用账号，避免绕过或改变
  其原计价语义。新增备用请求仍受个人周额度和策略预算保护，不重复扣用户美元钱包。
- 支出硬限制按策略执行；全站页面展示汇总，尚无另一套独立的全站共享资金上限。
  金额为供应商名义 USD，不能未经核实币种和充值汇率便当作现金实付。
- 没有真实供应商 Key／价卡／批准预算前，不宣称已经验证真实 CLI、VSCode 或供应商账单。
  自定义别名可能在主池全不可调度时从选择器回落名单消失，但已配置型号的请求不依赖该名单准入。
- API 原生回执与费用在专属管理页和固定额度账本中记录；没有发票自动对账或已结算差额的专属纠正界面。

## 数据与恢复

新增 `270_api_fallback_metering.sql` 和 `271_api_fallback_control.sql`；预计生产迁移总数
319 → 321。它们不修改旧迁移、不初始化生产策略、不改变原周期和钱包起点。

原请求表新增 `metering_source`，旧行默认 `subscription`。API 固定扣点为 `api_fallback`，
沿请求开始时间归属原 Codex/Grok 周周期；不参加订阅百分比观察、校准及容量折算。
个人重置仍覆盖当前周期已结算请求，尚未确定的在途费用继续保留。

策略审批版本、事件和 API 固定原始扣点禁止改写；尝试记录保留冻结价卡和倍率。
个人与策略预算按固定顺序加 PostgreSQL 事务锁，跨 Key 共用，在途／未知费用均占用预算。
发送前复查数据库中的管理员身份、启用状态、Key、分组、账号及策略版本。

付费转发每次只发送一个上游尝试；断流、超时或无可信 usage 不自动重放。
现有有界后台 worker 把超过网关期限的中断任务归为待核实，不按 TTL 释放可能已发生的费用。
真实回执超过成本上界时仍完整记账，并阻止后续付费；管理员须在事故之后重新审批才可恢复，
旧版本晚到的超界回执也会触发保护。Codex/Grok 原准入仍保持 shadow。
