# API 实验 Key 备用

管理员在「API 备用」新增策略，选编程入口、实际型号及自己名下同平台的 API 实验 Key。
保存默认关闭；启用前确认实验 Key 的同型号 Responses 能力。普通用户不能使用此备用。
客户端继续使用原来的编程 Key，不需要改配置。当前仅接管普通 HTTP Responses 文本和本地工具；
带供应商状态的旧会话需新开会话。

所有支持该型号的主订阅均确认到期或有新鲜的官方耗尽读数时，才接管。
账号到期以账号中已配置的自动停用到期时间为准；繁忙、网络错误、空池、未知状态均不触发。
主订阅恢复后优先走订阅。可在管理员页只读预览，不会调用模型。

新策略只保存实验 Key 和分组编号，不保存 Key 明文，不新增价卡或扣点倍率。
接管重新走站内实验入口的鉴权、模型名单、并发、额度和计费；
GlobalAI 继续使用已有供应商请求凭据和后台账单结算。
费用只归实验账本，不写入旧备用点数账本。实验待账单语义保持不变，仍可能有迟到结算。
发送前复核两把 Key、策略及订阅池；单请求只允许一次上游发送。

无数据库迁移；旧计点策略、尝试及费用记录保留。上线不创建或启用策略。
