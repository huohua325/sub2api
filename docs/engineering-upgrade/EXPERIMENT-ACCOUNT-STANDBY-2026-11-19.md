# GPT 实验账号作为编程备用

管理员在「账号管理」编辑已有的 GPT 实验账号，在「仅作编程备用」勾选 Codex、统一编程对应分组。正常分组保持原来的 API 实验分组；无需用普通分组绑定、创建第二把站内 Key 或逐个型号建策略。「API 备用」继续保留旧策略和历史。

统一编程只在已解析为 GPT 路由时允许此备用。采用当前模型名单及同型号 Responses 能力，不替换成其他模型。账号需已探测出支持 Responses，或在原有账号设置中明确设为强制 Responses。首版仅管理员、普通 HTTP Responses 文本和本地工具；供应商绑定的旧会话不能随接管迁移。

只有当前入口支持该型号的订阅全部确认到期或官方额度耗尽时才接管。个人额度不足、临时繁忙、普通限流、502、证据未知或空池不触发。已开启的旧策略优先，不自动迁移；账号复制不继承新配置。

账号配置复用 `accounts.extra`，无迁移。备用关系不作为普通调度绑定，发送前再次确认账号、分组、管理员 Key 及订阅状态。实验链路沿用原使用者和 Key ID、目标实验分组的准入及同一本实验账本。无订阅折算，不变更个人周期，不发真实付费探针。
